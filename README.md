# ps3-world-editer

This repository now includes a Linux-focused **PS3 Minecraft World Editor** prototype at `ps3mc_editor/`.

## Run

```bash
python3 -m pip install PySide6 nbtlib
cd ps3mc_editor
python3 main.py
```

## Launcher options

- Shell launcher: `ps3mc_editor/start_editor.sh`
- Desktop entry template: `ps3mc_editor/ps3mc-editor.desktop`
